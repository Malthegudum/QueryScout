# Statistics Denmark

Use this source for official Danish statistics from StatBank Denmark.

Workflow:
1. Search for a relevant table.
2. Inspect the table metadata.
3. Identify the exact variable codes and allowed value codes.
4. Query the table using only verified codes.
5. Inspect the result and revise the query if needed.

Rules:
- Never invent table IDs.
- Never invent variable codes or value codes.
- Always inspect table metadata before querying.
- Prefer the most specific table that answers the user's request.
